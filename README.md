# Hollow Games iOS Builder

Build a private iPhone IPA from **your own GOG Mac copy** of Hollow Knight or Hollow Knight: Silksong. Includes touch controls, a layout editor, controller input, actual presented FPS, 60/120 Hz options, lossless compression and guest-local LiveContainer compatibility fixes.

**Status: experimental, clean builds verified.** The earlier privately assembled ports work on an iPhone 15 Pro / iOS 27.0.1 in LiveContainer with JIT disabled. Both public build recipes now complete from clean inputs, including byte-verified compression and IPA checks; see [validation](docs/VALIDATION.md). Do not interpret that device result as a completed full-campaign test or verification of every output generated by this repository.

## Supported inputs

| Game | Required Mac release | Engine |
| --- | --- | --- |
| Hollow Knight | GOG 1.5.12620 | Unity 6000.0.61f1 |
| Hollow Knight: Silksong | GOG 1.0.30000 | Unity 6000.0.50f1 custom branch |

Choose the GOG **Mac `.pkg`**, an extracted `.app`, or a folder containing exactly one complete Mac game `.app`. The native binaries and every original managed assembly must match the recorded SHA-256 hashes. A folder containing only textures/assets is insufficient. Different updates, Steam builds, APKs, Linux installers and Windows folders are not interchangeable inputs. Unsupported builds stop with an explanation; there is no force switch.

The package is extracted as data with `pkgutil --expand-full`. Installer scripts and the Mac game executable are never launched. The builder executes the game's Mono runtime on the Mac as a compiler to generate native helpers.

## Requirements

- Apple Silicon Mac, ARM64 Python **3.10 or newer**, full **Xcode 27** with iPhoneOS SDK. Unity Editor and Homebrew are not required.
- Xcode command-line tools selected, with its first-launch setup completed by you.
- Plan for **30 GB free for Hollow Knight / 40 GB for Silksong**, including package extraction, working copies and output. These are conservative allowances, not the installed app sizes. Build one game at a time on a small disk.
- LiveContainer configured to sign/import your own apps. Follow its [official instructions](https://github.com/LiveContainer/LiveContainer); no certificates or signing account are included here.

If macOS's `python3` is too old, install an ARM64 Python from [python.org](https://www.python.org/downloads/macos/). No game data is uploaded to a server. Hollow Knight's input bridge needs Microsoft Roslyn: the builder downloads a hash-pinned compiler package from NuGet into your local cache on first use. You can supply an existing `tasks/net472` directory with `--csc-directory` instead.

## Build

Run `zsh Build.command` in Terminal to choose your package/folder and output location. If you prefer double-clicking the launcher, first run `chmod +x Build.command` once; browser uploads/downloads may not preserve its executable permission. It creates a local Python environment and downloads the listed Python dependencies. Alternatively, use the commands below.

Open Terminal in this repository:

```sh
export DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python build.py doctor
```

For Hollow Knight:

```sh
python build.py build --input "/path/to/hollow_knight_enUS_1_5_12620_.pkg" --work "$HOME/Downloads/HK-iOS-build"
```

For Silksong:

```sh
python build.py build --input "/path/to/hollow_knight__silksong_enUS_1_0_30000_.pkg" --work "$HOME/Downloads/Silksong-iOS-build"
```

Or pass `--input "/path/to/Hollow Knight.app"` / `--input "/path/to/Hollow Knight Silksong.app"`. Always use a separate work directory outside your original game. `--output "/path/to/Game.ipa"` selects the IPA destination. `--jobs 1` lowers compiler memory pressure.

On success the console prints `READY`, and the work folder contains an unsigned IPA plus its JSON checksum/size report. Import the IPA in LiveContainer, **leave JIT disabled**, then launch. Use Options → Menu for menus and Options → Play for gameplay. Options also contains the layout editor, controller mode, 60/120 Hz and actual FPS display.

The same command resumes completed stages after interruption. If a compiler or compression step fails, keep the work folder/logs and consult [troubleshooting](docs/TROUBLESHOOTING.md). A partial IPA ending in `.building` is not an installable release.

## Compression and artwork

- Hollow Knight: loose level/assets/texture streams are packed into `data.unity3d` with 128 KiB LZ4HC blocks; audio/video `.resource` files stay external.
- Silksong: every original bundle is recompressed with LZ4HC. Catalogs and non-bundle files stay in place. The slow full-LZMA experiment is deliberately excluded.
- Every decompressed archive node is SHA-256 checked before replacing the converted copy. No texture downscaling, audio transcoding or content trimming is performed.
- Prior measured private builds: HK roughly **1.18 GB IPA / 1.54 GB installed**; Silksong **2.41 GB IPA / 2.93 GB installed** with the expanded native helpers. These are reference measurements, not guaranteed output sizes.
- This repository includes generated HK control artwork and generated Silksong utility icons. Silksong's remaining default controls use original vector fallback symbols, rather than redistributing sprites from the community APK. You can provide your own PNGs using `--controls "/path/to/icons"`; see [artwork](docs/ARTWORK.md).
- The default app icon is recovered from your supplied Mac copy. Use `--icon "/path/to/your-icon.png"` to replace it.

## Publishing and scope

The repository contains source, generated control art, version fingerprints and documentation. It excludes the game, engine binaries, original installers, native compiled companions, IPAs, saves and signing material. **Do not attach generated IPAs or game files to public releases.** Use only copies you are entitled to use; this project does not provide a license to the games or bypass store ownership checks.

No phone connection is required to build, and these scripts never install/uninstall an app or access a device's saves. Existing working ports and original packages remain separate from the public builder.

See [architecture](docs/ARCHITECTURE.md), [third-party provenance](THIRD-PARTY.md) and [validation](docs/VALIDATION.md).
